# Validation evidence and Apple acceptance checklist

Implementation host: Linux, 2026-10-21. A temporary **official Swift 6.2 compiler** and its runtime libraries were installed entirely under `/tmp`. No macOS/iOS device access, Xcode or Apple SDK was available. These are portable and static results, not an Apple app launch or screenshot.

## Executed checks — milestone two

- **MeetupCore: 115 XCTest tests pass**, with warnings treated as errors, in the integrated package alongside the pinned provider. This includes 27 calendar/parser, 24 recurrence, 14 course, 17 public-identity and 10 matching/nearby/display-window tests, plus existing transport, RSS, Bitcoin and portal tests. No test was skipped in the final run: the captured live ICS fixture was supplied explicitly. The fixture itself is optional and not checked in; ordinary CI skips only that captured-response test.
- **MeetupNostr: 19 tests pass in debug and release.** The final integrated debug run includes the same 19 tests. Official BIP-340 vectors cover exact deterministic signatures and 15 fixed-length verification cases, including 10 negative cases; four variable-length messages are rejected under the Nostr 32-byte policy. NIP-01 IDs use independent expected hashes, exact UTF-8 and escaping. Tampering, byte lengths/scalar bounds, integer-token rounding, malformed ignored JSON fields, property-list roundtrips, production auxiliary randomness and actor isolation are covered. Composed/decomposed tag values and the Kelvin-sign tag key remain byte-distinct. Use `decodeJSON(_:)` for untrusted wire input; generic Codable cannot validate original numeric tokens.
- **Actual app models/state: 15 portable tests pass** via both the normal SwiftPM path and `test_local_models.py --source-only`. The latter compiles the actual dependency-free core sources directly; both paths compile LocalModels, EventFormatting, AppLocalization and LearningStore without UI stubs. Tests cover legacy cache/plan decoding, civil all-day export dates, localized search, bounded preview imports, dropped claims/signatures, demo/live isolation, disabled product signing, cancellation/retry, obsolete request generations, persisted list relationship fallback, and reset replacing the API client so pre-reset details cannot reappear.
- **CalendarICS: 12 portable tests pass.** Covers CRLF envelope, injection/escaping, control characters, stable UIDs, UTF-8 folding and 75-byte boundaries, UTC timestamps, invalid dates/ends, safe URLs, VALUE=DATE, a 25-hour DST day and a civil day beginning at 01:00.
- **Captured real-response decoder checks:** 323 directory records, 43 portal events (30 absent ends), 50 RSS articles, 46 courses and 25 lecturers decode. Course 44 detail preserves its explicit UTC 17:30–19:00 appointment; lecturer 144 retains four course relationships. The ICS fixture yields 629 unique VEVENTs, zero parser warnings and no invented venue coordinates. VTIMEZONE observances do not become events. These October 21 responses do not establish future availability and are not shipped as demo content. The captured feed has no RRULEs, so recurrence coverage is synthetic.
- **Calendar regressions:** complete portal aggregate or ICS fallback, sanitized failure/source/freshness provenance, bounded WEEKLY/MONTHLY rules, EXDATE/COUNT/UNTIL, stable occurrence IDs and civil dates. Santiago 2026-09-06 starts at 01:00 without shifting later weekly starts/ends; Apia's entirely skipped 2011-12-30 remains invalid. All-day entries stay visible through their exclusive civil end; date filters preserve source Y/M/D across device zones. Unsupported rules/exceptions and expansion caps remain visible limitations.
- **Swift 6 syntax parsing passes for all 25 app sources**, targeting `arm64-apple-ios26.0`, `arm64-apple-ios26.0-simulator` and `arm64-apple-macosx26.0`, including the device-only VisionKit branch. Imports and SDK overloads are not resolved by parsing.
- **Portable project validation passes:** the 35-object OpenStep graph, target memberships, both local products, exact single-pin package and Xcode workspace locks, six Debug/Release × SDK settings, scheme, plist/ATS/location/calendar/file entitlements, assets, 57-route matrix, and 516 localization keys per DE/EN/ES locale with exact placeholder parity. Both products are linked so app builds also compile the provider path.
- The initial project was independently parsed with Foundation `PropertyListSerialization`. Icons have correct dimensions/opacity and regenerate deterministically. Parent reviews also compiled actual Foundation/state sources with Linux-only adapters; these checks do not establish SwiftUI or Apple API correctness.

The final integrated test log is `/tmp/einundzwanzig-milestone2-final-tests.log`; crypto debug/release logs are `/tmp/einundzwanzig-meetup-nostr-debug-tests.log` and `/tmp/einundzwanzig-meetup-nostr-release-tests.log`. ## First Mac / iPhone acceptance pass — outstanding

1. With Xcode 26, run all three unsigned builds: iOS Simulator, generic iOS device and native Mac. Verify local Swift package linking, SDK overloads, asset compilation, shared scheme, localized resources and no unexpected entitlements.
2. Run **My Mac** with local/ad-hoc signing and an iOS 26 simulator with no development team or secrets. Complete nickname onboarding, relaunch and edit profile; verify persistence and separate Flutter data container. Try explicit reset from onboarding Settings and after ordinary use.
3. Explore preview mode offline. Star sample groups, save a sample plan/note, switch to live and verify sample actions do not appear as real favorites/plans. Switch back and confirm sample plans remain marked Preview. Sample QR imports must never become trusted.
4. Load live directory/news/calendar and courses/lecturers. Search Wien, Berlin and a city containing multiple groups; star exact IDs and relaunch. Open maps and Apple Maps. Test network offline/failed endpoint/invalid server, retry and cached source labels. Exercise nested course/lecturer links after relaunch and reset during an in-flight detail request; deleted records must not reappear.
5. Open an event. Change a Going/Maybe plan and note, relaunch, remove it. Confirm the UI says **local only** and makes no portal or Nostr RSVP request. Cancel calendar review; it must not say Saved. Save deliberately, then check actual Calendar. Export/import a Unicode multiline `.ics` file. Deny Mac calendar access and use file fallback.
6. On a supported physical iPhone test QR camera permission granted/denied/restricted, interruption/background and dismiss. Scan a rolling source QR; it should extract unverified metadata only. Confirm camera unavailable on simulator/Mac and manual/file input still works. Select photo QR images on both platforms; test malformed/large images, multiple QR codes, HEIC containers and the intentional single-image-container restriction. Try invalid JSON, a large file, private-key-like data and unknown fields.
7. Verify Badges grouping/search/details/deletion and unverified/demo labels. Reputation must show unavailable score and zero trusted badges, with no signed QR, ownership claim or successful verification state.
8. Read a news excerpt; original link/share works, read mark persists. No WebView executes untrusted RSS HTML. Check bad/relative URLs remain bounded by decoder validation.
9. Refresh Bitcoin; change server while request is in flight, then reset during another request. Old snapshots must not populate under the new source/reset. Exact decimal conversion should retain sats, reject excessive precision and show price timestamp/estimate.
10. Change language DE/EN/ES and appearance; relaunch. Test system language, very long translated labels, maximum Accessibility Dynamic Type, VoiceOver focus/order, keyboard navigation, high contrast, Reduce Motion and Reduce Transparency. Home control row should adapt vertically and custom glass become opaque when requested.
11. On Mac verify sidebar selection, ⌘1…5, ⇧⌘S, ⌘R, Settings menu, file importer/exporter sandbox access and multiwindow state synchronization. Confirm no camera entitlement is requested on Mac.

12. Request current location only after tapping its control. Test approximate/precise fixes, denial/restriction, disabled services, cancellation, timeout and planned-place search without GPS. Check radius/date filters, source group matching and all-day civil dates near DST transitions.

Any Apple compile, runtime, privacy-permission or accessibility issue discovered in this pass must be fixed before distribution. Future security integrations need their own official vector suites and review before any unavailable state is enabled.
